NEXA Exam Monitoring System

Comprehensive Features & Capabilities Overview

AI-Powered Proctoring & Security

Real-Time Face Detection

Utilizes advanced AI (face-api.js) to track the student's face continuously. Triggers instant warnings if no face is detected or if multiple faces appear in the same frame.

Camera & Hardware Integrity

Actively polls camera state to detect disconnections, muted tracks, or physical black-frame obstructions (e.g., covering the lens).

Strict Anti-Cheat Engine

  • Detects tab-switching & window minimizing.
  • Disables Copy, Paste, Right-Click, and Selection.
  • Blocks Developer Tools shortcuts (F12, Ctrl+Shift+I).

Automated Warning System

Maintains a live strike system (configurable). Exceeding the maximum allowed warnings (e.g., 3) results in automatic exam termination.

Media Recording & Cancellation

Persistent Session Recording

The entire exam session (Video + Audio) is recorded in the background and uploaded asynchronously to the secure server as WebM blobs upon submission.

Web-Audio Noise Cancellation

Built-in dynamics compression and high-pass filters strip out background rumble and normalize microphone levels in real-time before saving the recording.

Admin & Question Manager Portals

Live Proctoring Grid

Admins can watch live feeds (auto-refreshing snapshots) of all concurrently active students in responsive 2x2, 3x3, or 4x4 grids.

Interactive Analytics Dashboard

Leverages Chart.js to map pass/fail ratios, warning distributions by exact type, and top student performances.

Exam Configuration Sandbox

Question Managers (QM) can spin up exams with dynamic total times, passing criteria, custom instructions, and option shuffling.

Recording Playback

Admins have dedicated playback controls in their Results table to fetch and review any compiled exam recording directly from the server.

Student Experience

Streamlined Authentication

Frictionless login combined with an automated procedural Mathematics CAPTCHA for bot protection, entirely bypassing slow SMS/OTP layers.

Interactive Question Palette

Students can navigate cleanly through color-coded question grids showing answered, unanswered, and active statuses.

Result & Certificate Exports

Students can instantly export their results in CSV/Text or rich PDF formats, alongside localized playback for their own exam recordings.

Modern Dynamic Appearance

High-quality "Glassmorphism" UI panels, fluid theme switching (Light/Dark mode), and toast-based notification alerts.
